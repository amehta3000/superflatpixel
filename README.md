# SuperFlat

A modern web app for creating pixel art effects from images with customizable shapes, rotation, and filters.

## Features

- 🎨 10 unique pixel shapes (square, circle, hexagon, rectangle, triangle, diamond, star, plus, cross, backslash)
- 🔄 Individual pixel rotation (0-360°)
- 🎚️ Adjustable pixel size (0-50px)
- 🌈 Background color customization
- ✨ Advanced effects:
  - Blur (0-10px)
  - Saturation (0-200%)
  - Posterize (2-256 levels)
  - Pixel spacing (0-10px)
  - Grid lines with custom colors
- 📥 Drag-and-drop image upload
- 💾 Export as JPEG

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Tech Stack

- React 18.2.0
- Vite 5.0.8
- HTML5 Canvas API
